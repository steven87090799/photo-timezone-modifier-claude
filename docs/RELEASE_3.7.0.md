# 3.7.0 修復與介面調整

## 已修復

| 問題 | 處理方式 |
| --- | --- |
| 光圈／快門經 ExifTool 換算後，極小精度差異被當成 EXIF 遺失 | JPEG／HEIF 優先完整複製 EXIF 區塊並逐位元組驗證，涵蓋相機私有標籤與縮圖。 |
| 無可擷取 EXIF 區塊的來源仍可能有拍攝數值精度差異 | 只對指定 EXIF 拍攝測量值容許極小誤差，重複數值依數值排序核對；日期、時區、GPS、XMP、缺少欄位仍嚴格核對。 |
| JPEG 複製 IPTC 後，目的檔既有摘要可能不同步 | 同步複製來源 Photoshop IPTCDigest，保留中繼資料警告檢查。 |
| 原生 HEIF 使用 nclx 色彩屬性，ExifTool 未實際加入 ICC，導致全部被拒絕 | 對剛產生的單一色彩屬性 HEIF 準備可寫入 ICC 的屬性；ExifTool 負責更新容器位址與大小，再逐位元組核對 ICC 並用 ImageIO 解碼。影像仍由 macOS 原生編碼。無法安全辨識的容器拒絕輸出。 |
| 已存在的來源警告被當成新增損壞 | 只有完整 EXIF 區塊逐位元組一致、前後警告完全相同時容許來源既有警告，結果仍明示警告；新增警告不放行。 |
| 快速重複開啟選檔面板可能疊出多個視窗 | 兩個處理頁共用單一面板管理；輸出／儲存採原生附屬面板。混合相片／資料夾匯入沿用 standalone，避免既有 macOS sheet 選取失效。 |
| HEIF 壓縮時顯示「待處理」、診斷頁忽略壓縮工作 | 顯示原生編碼階段，診斷頁分別列出相片處理與影像壓縮狀態。 |

## 介面

- 使用 macOS 原生 Liquid Glass 和系統視窗材質；降低透明度時使用實色表面。
- 三個分頁固定靠右，設定、清單、預覽及結果採一致布局。
- 保持可連續捲動的相片清單；照片資訊維持橫向排列、次要資訊可展開。
- 壓縮預覽改成左右並列，可隱藏預覽以放大清單。
- 直接顯示完成／失敗、容量變化和儲存全部；可只查看失敗，並僅重試失敗項目，保留成功結果。
- 移除影像壓縮 CSV 匯出入口及其程式碼；逐張錯誤仍可在清單與預覽檢視。
