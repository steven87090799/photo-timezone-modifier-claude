# 3.7.2 分頁切換效能

## 修正

- 三個頁面共用固定的 NavigationSplitView 與工具列；切換時只更換側欄及內容，不再銷毀、重建整個分割視窗。
- 關閉頁面切換的隱式布局動畫，減少原生玻璃及工具列重新布局。
- 保留壓縮的兩張有限尺寸縮圖及一份已產生的預覽檔，切回來不再重新壓縮整張照片。這些快取沒有背景計算；更換來源、品質或格式時仍會重新核對。
- 快取來源的檔案屬性核對移到背景執行緒；批次處理仍遵守寫入前重新核對的既有規則。
- 離開壓縮頁先停止預覽；引擎卸載延後 150ms，快速切回可取消重複卸載。持續離開時仍停止閒置 WebKit／worker；不影響正在進行的批次處理。
- 診斷頁保存儲存空間快照，不在每次進入時重新掃描；「重新計算」仍可更新。資源採樣只在診斷頁顯示時執行。
- 診斷卡片延遲建立，壓縮篩選／預覽顯示設定保留於切頁之間。
- WebKit 容器直接保存非空的 view，移除建立視圖期間可能因卸載而失效的強制解包。

## 範圍

沒有變更影像編碼、EXIF／ICC 寫入、時區與 GPS 規則。關閉程式仍會停止子程序並移除工作暫存。本輪未新增或執行本機自動測試套件。
