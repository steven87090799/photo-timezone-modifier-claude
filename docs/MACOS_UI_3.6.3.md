# 3.6.3 介面與操作

## 調整內容

- 三個頁面的切換固定在 macOS 原生工具列；採系統外觀、半透明側欄、分組設定與原生主要操作按鈕。
- 相片處理的縮圖、相機／曝光摘要、拍攝時間與三種時區、GPS 狀態／經緯度／高度橫向排列，縮減一般資訊區高度。其他 EXIF 資料由「顯示更多」展開並獨立捲動；掃描報告維持底部。
- 壓縮清單以較矮的橫向列顯示檔案／相機、拍攝時間／時區／GPS，以及處理狀態／容量。
- 「已完成」正下方用綠色與向下箭頭表示容量減少，用橘色與向上箭頭表示增加。下一行顯示原始大小 → 輸出大小；滑鼠停留可查看實際 bytes 與容量差額。底部批次摘要與右側預覽也突出容量比例。
- 品質滑桿改為沒有密集刻度的原生連續軌道；輸入仍四捨五入為整數，編碼器與數字顯示一致。
- 並行可選 1～8 張，既有自訂數量與預設 2 張保留。大尺寸照片與記憶體需求較高的格式，仍可能只有 1～2 張實際同時處理；選 8 不代表強制執行 8 張。

## 儲存與中繼資料

開始壓縮先產生暫存結果；選擇輸出資料夾不會自動儲存。完成後用「儲存單張」或「輸出 → 儲存全部圖片／儲存為 ZIP」。關閉程式會清除暫存結果，請先儲存。

本次調整未更換編碼器、建議品質、容量計算公式、檔名政策與中繼資料讀寫規則。六種格式、預覽／比較、報告與 Webhook 保留。

## 建置與確認範圍

執行 `./build.sh` 產生 `dist/PhotoTimezone-macOS.zip`，建置腳本會在非 FileProvider 的暫存目錄解壓並確認簽章與 arm64 架構。

本次已查看原生壓縮頁的空清單介面與品質滑桿；尚未以大量相片檢查新橫向列在所有視窗尺寸下的視覺表現。本次沒有重新執行完整功能／照片輸出回歸測試；3.6.2 的輸出驗證不能當成新介面已完成驗收。
